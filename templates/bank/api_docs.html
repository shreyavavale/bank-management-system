REST API Documentation

The API is built with Django REST Framework. Log in first (session authentication) or use HTTP Basic authentication. Responses are JSON, and every list endpoint is paginated (10 records per page).

Endpoints
ResourceURLMethodsNotes
Customers/api/customers/GET, POST, PUT, PATCH, DELETEFull CRUD. Detail URL: /api/customers/<id>/
Accounts/api/accounts/GET, POST, PUT, PATCH, DELETEFull CRUD. Account number is auto-generated; balance changes only via deposit/withdrawal.
Deposits/api/deposits/GET, POSTPOST body: account, amount
Withdrawals/api/withdrawals/GET, POSTRejected with HTTP 400 when balance is insufficient.
Transactions/api/transactions/GETRead-only ledger so history cannot be altered.
Example: deposit using curl
curl -u admin:admin123 -X POST http://127.0.0.1:8000/api/deposits/ \
     -H "Content-Type: application/json" \
     -d '{"account": "100012345678", "amount": "2500.00"}'
